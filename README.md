# Mean Shift Clustering and Value at Risk (VaR) Analysis

## Overview

This project combines Mean Shift clustering and Value at Risk (VaR) analysis to explore data patterns and evaluate potential risk. The goal is to group similar data points and assess the level of risk within each group.

## Objectives

* Identify clusters using Mean Shift clustering
* Analyze data patterns without predefined cluster numbers
* Measure potential risk using Value at Risk (VaR)

## Method

The project applies **Mean Shift clustering**, a non-parametric clustering technique that automatically determines the number of clusters based on data density.

To evaluate risk, **Value at Risk (VaR)** is used to estimate the potential maximum loss within a given confidence level.

## Process

* Data preprocessing and preparation
* Mean Shift clustering implementation
* Cluster analysis
* VaR calculation for risk measurement
* Interpretation of results

## Tools

Python, Pandas, NumPy, Scikit-learn, Matplotlib

## Output

The project produces clusters of similar data points and provides risk estimation using VaR, helping to understand both data structure and potential losses.

## How to Run

Open the notebook file (`.ipynb`) and run all cells.
Ensure required libraries such as pandas, numpy, scikit-learn, and matplotlib are installed.

## Conclusion

This project demonstrates how clustering and risk analysis can be combined to gain deeper insights into data patterns and potential risks.
